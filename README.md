# gitea task issues

这是一个dsh插件,用于处理工作区与gitea的仓库绑定与issues管理(提供dsh工具)

Api: https://tea.2sxo.com/swagger.v1.json 

## 功能列表
* 全局dash,在自动化任务下面
* 多服务器管理,密钥管理
* 工作区与仓库绑定,服务器+仓库,自动侦测
* 全局issues看板,位于全局dash
* 工作区issues看板,位于项目右侧面板
* issues管理(几乎实现所有可用Api)
    - 列出/搜索
    - 查看详情
    - 创建/删除/编辑
    - assets附件
    - 分配/blocks
    - 评论的查看/删除/编辑
    - 订阅/Pin/Label/Lock/times
